# 🎮 KBC Game (Kaun Banega Crorepati) - VB.NET

The **KBC Game** is a quiz-based desktop application developed in **VB.NET**.  
It is inspired by the popular TV show *Kaun Banega Crorepati*, where users answer multiple-choice questions to win virtual prize money not real.

---

## ✨ Features
- 📝 **Multiple-Choice Questions** with four options.  
- 💰 **Virtual Prize Money System** (increasing with each correct answer).  
- 💡 **Lifelines** (50-50, Audience Poll).  
- 🎵 **Sound Effects & Animations** for a real game-like experience.  
- ⏱️ **Timer for each question** for Answer before time
- ❌ **Game Over on Wrong Answer** with earned prize displayed.  

---

## 🛠️ Tech Stack
- **Language:** VB.NET  
- **Framework:** .NET Framework / Visual Studio  
- **UI:** Windows Forms
